# ByteBloom

A coding learning app with an adaptive challenge workspace and a progressive AI mentor named Bloom.

For existing Supabase projects, run `backend/supabase/migrations/20261114_real_learning_streak.sql` and `backend/supabase/migrations/20261114_lesson_progress.sql` in the SQL Editor after the learner-progress migration. They add/backfill real learning activity dates for streaks and create persisted lesson-path progress.
